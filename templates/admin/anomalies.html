Exemple : 5 annonces a ~500 FCFA + 1 annonce a 50 000 FCFA. Le Z-classique rate l'outlier, le MAD le detecte.

Methode Mediane Moyenne MAD Z du prix 50 000 Detection
Z-classique {{ demo.mediane }} {{ demo.moyenne }} — {{ demo.z_classique_50000 }} {% if demo.detecte_par_z_classique %} Detecte {% else %} Rate {% endif %}
MAD robuste {{ demo.mediane }} — {{ demo.mad }} {{ demo.z_mad_50000 }} {% if demo.detecte_par_mad %} Detecte {% else %} Rate {% endif %}
Argument clé : le breakdown point du Z-classique est 0% (1 outlier peut le fausser), celui du MAD est 50% (il faut corrompre la moitié des données). C'est pourquoi le MAD est préféré en production.
